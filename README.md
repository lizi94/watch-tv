# 长辈版看电视 App（电视盒子 / 手机都能装）

这是一个给**家里老人**用的看电视软件。原版功能很强，但按钮小、字也小、选项多，老人容易按错、找不到回来的路。这个版本把界面重做了一遍：**字大、按钮大、能用遥控器少按键操作、按错也不会迷路**。

改造重点在**电视版**（老人主要用电视看）。手机版保留原版触摸操作，把能共用的设置项补齐了——所以**这几个包功能不完全一样**，下面表格里都标清楚了。

> 本软件**不带任何电影、电视剧、直播内容**。片源要靠你自己添加一个「配置」地址才有内容。

---

## 一、四种包，先选一个

从 v6.4.6 起，一个版本出**四个包**（两个分支各两个），当前版本是 6.5.0（①②）/ 6.5.1（③④）。播放、搜索、收藏、历史、长辈设置这些**完全一样**，差别只在「开机自启 / 接管桌面 / 应用列表 / 体检页」这几件事上：

**③④ 只差一件事**：③ 会把自己声明成「电视桌面」（`HOME`），所以在体检页里能**直接把看电视设成默认桌面**，按主页键不弹「选择桌面」框；④ **不声明**，永远不会抢桌面，靠无障碍服务「一看见电视桌面就切回来看电视」。

**怎么选：**

- **手机 / 平板** → 装 ①，它是唯一为触摸屏做的。
- **电视，想保留电视自带桌面，只要求开机自动进软件、按主页键能回来** → 装 **④ 守护版**。最稳，不碰桌面归属。
- **电视，想彻底把看电视当成机顶盒（按主页键直接回来、不弹任何选择框）** → 装 **③ 桌面版**。
- **拿不准** → 先装 ④；用着觉得还想更彻底，再卸载换 ③。

四个包**不能同时装**（内部包名相同），换包前先卸载。标准两个包是 `6.5.0`、自启两个包是 `6.5.1`，④ 的版本名后面还多一个 `-guard` 后缀——就是为了让你在「设置 → 应用信息」里一眼看出装的是哪一个。

> ④ 不声明桌面，所以体检页第四项会明确写「**本版本未声明桌面，不能设为默认桌面**」——这不是坏了，是这一版的设计。想当桌面请换 ③。

## 三、装哪个包？

**先按第一节选定是哪一种，再按「设备位数」挑文件名。** 每个 Release 里只有 **2 个 APK + 1 个 `MD5.txt`**：

| 你要的包 | 目录 | 64 位设备装 | 只支持 32 位装 |
|---|---|---|---|
| ① 手机版 | `v6.5.0-mobile` | `mobile-arm64_v8a.apk` | `mobile-armeabi_v7a.apk` |
| ② 标准电视版 | `v6.5.0-leanback` | `leanback-arm64_v8a.apk` | `leanback-armeabi_v7a.apk` |
| ③ 桌面版 | `v6.5.1-home` | `leanback-home-arm64_v8a.apk` | `leanback-home-armeabi_v7a.apk` |
| ④ 守护版 | `v6.5.1-guard` | `leanback-guard-arm64_v8a.apk` | `leanback-guard-armeabi_v7a.apk` |

**不确定装哪个？** 先装带 `arm64_v8a` 的那个；提示"应用未安装"或打开就闪退，就换同目录里的 `armeabi_v7a` 再试一次。两个都装不上，说明设备太老，跑不起这个版本。

> 想知道电视是 32 位还是 64 位：装错时只会提示"应用未安装"，换另一个就行；或用 adb 看 `getprop ro.product.cpu.abilist`，出现 `arm64-v8a` 就是 64 位。

> ② 标准电视版**不带自启、不带守护、不带应用页**，就是一个"界面适老化的普通电视 App"——如果你只想让老人手动点开看，装它最省事。

安装包在对应 Release 里下载。每个 Release 里都有一个 `MD5.txt`，写的就是这两个包的 MD5，下载后可以自己核对（`certutil -hashfile 文件名 MD5`）。

## 四、③④ 装好后先做一次体检

①② 跳过这一节（它们没有体检页，也没有需要额外授权的服务）。③④ 装上就能用，但**建议打开「设置 → 长辈设置 → 启动与桌面体检」按一遍**——那里把需要系统配合的四件事集中在一页里，点右下角「一键检查并修复」会按顺序自动处理**下一件没做的事**（需要跳系统页时自动跳过去）。

### 4.1 体检页上的四件事

| 检查项 | 做什么 | 为什么需要 |
|---|---|---|
| **开机就打开看电视** | 让软件开机后自动出现 | 老人不会自己去找软件 |
| **让电视别把看电视关掉** | 把本软件加进"允许后台运行 / 电池不优化"白名单 | 有些电视看完片子回到桌面后过一会儿就把软件杀了 |
| **按主页键回到看电视** | 打开无障碍里的「看电视 · 桌面守护」 | 安卓规定任何 App 都不能自己开，只能你手动开一次 |
| **把看电视设为默认桌面**（部分电视不支持） | 让本软件直接当电视桌面 | 想彻底替代电视自带桌面时用；不支持就改用上一项 |

每行右侧的状态，含义都对得上：

| 状态文字 | 意思 |
|---|---|
| **已设置** | 这项好了 |
| **需要设置** | 还没弄，按 OK 跳过去开 |
| **已关闭** | 你自己关掉了（比如关了开机自启） |
| **电视桌面已经管了，不用再开** | 已经是默认桌面，守护服务没必要再开 |
| **已经是电视默认桌面了** | 「开机自启」这一项被桌面接管，不用单独设 |
| **本版本未声明桌面，不能设为默认桌面** | **只有 ④ 守护版会看到**——它按设计不声明桌面，想当桌面请换 ③ |
| **已开启但没在运行** | 权限给了但服务被系统掐了，按 OK 会显示「正在重新连接…请稍等几秒」自愈 |
| **只有「看电视」一个桌面（不建议）** | 这台电视上已经只剩本软件一个桌面候选（原厂桌面没了），属安全阀告警 |

四件都齐了会显示"都设置好了"。某台电视跳不过去时，会提示"这台电视不支持直接跳转，请到系统设置里改"。

### 4.2 手动打开「按主页键回到看电视」

体检页跳不过去时，自己找：

1. 电视上依次进入 **设置 → 无障碍 / 辅助功能 → 已下载的服务 / 已安装的应用**，找到「**看电视 · 桌面守护**」，打开它，确认「允许」；
2. 回到软件，按一下遥控器的**主页键**——大约 1~2 秒后应该自动切回软件，说明生效了。

> 不同品牌叫法不一样，常见的是「无障碍」「辅助功能」「更多设置 → 无障碍」。也可以在系统设置里搜「无障碍」。
>
> TCL / 雷鸟电视如果把这个服务藏起来：去「安全中心 / 权限管理」里放行一次，再回来打开。

### 4.3（可选）授权「通知使用权」

这一步**不做也能用**，作用是让系统不那么容易把软件从后台清掉：

**设置 → 通知 → 通知使用权 / 通知使用权管理**，找到「看电视」，打开。这个服务不读取任何通知内容。

### 4.4 这些怎么关掉

- **只想让主页键恢复正常**：体检页里把「按主页键回到看电视」对应的权限关掉（或去系统无障碍里关「看电视 · 桌面守护」）；
- **不想开机自动打开**：长辈设置里把「启动与桌面体检 → 开机就打开看电视」关掉，或直接把开机自启那一项关掉（体检页第一项会变成"已关闭"）；
- **③ 想换回电视自带桌面**：到电视的 **设置 → 应用 → 默认应用 → 主屏幕 / 桌面**，改回电视原来的桌面即可（本软件没有"一键还原"按钮，这是安卓系统的设置项）。

### 4.5 装了 ③④ 可能遇到的现象

| 现象 | 说明 |
|---|---|
| 从电视桌面进别的 App（比如相册），会被立刻拉回来 | 这是「按主页键回到看电视」的代价——它只管"桌面一出现就切回"，不区分你是按主页键回去还是开机就在桌面。临时要用别的 App，先在电视桌面连按两次主页键（放行 3 分钟，会提示「已放出 3 分钟，按主页键可回来」），或者把该项关掉。 |
| 按主页键后被拉回，但想留在桌面待一会儿 | 同上：桌面出现后 10 秒内**连按两次主页键**即放行 3 分钟（会提示「已放出 3 分钟，按主页键可回来」），期间系统应用（设置、相册等）都能正常用；再打开一次本软件立刻恢复接管。 |
| 开机后仍要等十几秒才自动出现 | 部分电视（如 TCL）会把第三方 App 的启动压到开机后几十秒。实测从"桌面出来再干等约 2 分钟"缩短到"约 10~30 秒"，剩下的卡在系统侧，App 端改不动。 |

> 桌面守护只做一件事：**看当前在前台的是不是电视自带桌面**（只比对包名，不读屏幕内容、不记录任何操作）。无障碍配置里已明确关闭「读取窗口内容」。

## 五、遥控器怎么按（每一页都写清楚）

这一节按**页面**讲遥控器上那几个键能干什么，全部按当前版本代码实测口径写。①② 是触摸操作，不用看这节（①② 也没有后面的「应用页」「体检页」两小节）。

### 5.1 四条通用规则

| 键 | 作用 |
|---|---|
| **方向键** | 移动蓝色粗框（选中项）。每移动一格一声短促「嘀」（长辈设置里可关「按键音」） |
| **确定 / OK** | 执行；按下有一声确认音 |
| **返回** | **除首页外，任何页面按返回都回首页**，不会退出软件。播放页是逐级退：先收起控制栏 → 再退出全屏 → 最后才回首页 |
| **菜单键** | 不同页面含义不同：首页＝筛选面板；播放页＝显示/收起控制栏；直播页＝调出控制栏 |

**首页的返回键只有一个含义**：**4 秒内连按三次**才退出（判断的是**相邻两次的间隔**都 ≤4 秒，三下最长可拖到 12 秒，老人按得慢也来得及）。第一下提示「再按两次返回键退出」，后两下不再提示。

首页返回还有几种特殊情况，都是有意的：

| 情况 | 按返回会怎样 |
|---|---|
| 停在「连接网络中…」启动画面 | 立刻进内容态（**这一下仍计入退出连按**）。否则没网时老人只能干等 |
| 正在「最近观看」的删除模式 | 先退出删除模式（**不计入**退出连按） |
| 焦点停在分类那一行 | 回到内容区第一个封面行（**不计入**退出连按）——「从分类行出来」不是「退出软件」 |
| 焦点不在第一行 | 列表滚回顶部、焦点落回首行（**照常计入**退出连按） |
| **③ 桌面版已被设为默认桌面** | **什么都不做**——和电视自带桌面一致（退出去也会被系统立刻拉回来）。只有上面两种情况例外：启动画面按一下进内容、删除模式按一下退出删除 |

> 另外，老人翻到很下面、或开着筛选弹窗 / 删除模式时按**主页键**再回来，画面会**自动复位**（关弹窗、退删除、列表回顶、焦点落回分类行）——不会卡在之前的位置。

### 5.2 首页

| 想干什么 | 怎么按 |
|---|---|
| 打开某一格 | 焦点移到封面／按钮上按 OK |
| 换分类 | 焦点移到「推荐 / 分类」那一行，**左右移动就自动换**（约 0.25 秒防抖，快速划过只会加载最后停下的那个，不用按 OK） |
| 重新加载当前分类 | 在分类上**按 OK**（这是唯一会"强制重载"的动作，空态/加载失败后重试就靠它） |
| 从内容区回到大按钮那一行 | 按**上** |
| 搜同名影片 | 「首页快速搜索」**开着**＝单击海报跳快搜（跨源搜同名）；**关着**＝直接进详情页自动择源。**长按海报没有任何反应**（6.3.8 起收掉，防老人误触） |
| 继续看上次那一集 | 在「最近观看」的封面上**按 OK**＝直接接着播。这一行永远是"显式续播"，不受「开机看上次影片」开关影响 |
| 删一条观看记录 | 在「最近观看」上**长按 OK** → 进入删除模式 → **单击**要删的那条（会先问一句） |
| 清空全部记录 | 已经在删除模式下**再长按一次 OK** → 问「确定清空全部记录吗」 |
| 筛选当前分类 | 按**菜单键**。推荐页、或这个分类本来没有筛选项时，只提示一句"该分类无筛选条件" |
| 进设置 | ②：功能行最右的「设置」；③④：标题区右上角的齿轮（功能行里没有「设置」） |

进首页时焦点**固定落在最上面那排大按钮上**（不落分类、不落标题），所以「一进来就迷路」从第一秒就避免了。

### 5.3 详情页（选集 / 换线路）

详情页从上到下依次是：影片信息 → 简介 / 收藏 / 换源 → **线路** → **选集** → **排序**。

- 方向键在几组之间移动，OK 选中；
- 选集是横向列表：左右移动，OK 直接播这一集；
- 换源只走详情页里那个看得见的「换源」按钮（点片名、长按片名都没有隐藏功能）。

### 5.4 播放中（点播）

**这一节的键只在「全屏播放 + 控制栏收起」时生效。** 控制栏一开，方向键就是在按钮之间正常移动焦点，OK 就是按那个按钮。

| 按什么 | 会发生什么 |
|---|---|
| **左 / 右** | 快退 / 快进，每按一下 10 秒。**按住不放会一直累加**（屏幕中间显示将要跳到的位置），**松开手才真正跳过去**——松开约 0.25 秒后生效，不用再按 OK |
| **上**（松开时） | 调出控制栏。接近片头时会直接选中「片头」按钮、接近片尾时选中「片尾」，一按就跳过去 |
| **长按上**（约 1 秒） | 临时倍速（只在正在播放时有效），浮层显示当前倍数；**松开手立刻回到设置里那个倍速**（默认 1.0） |
| **下**（松开时） | 调出控制栏（同上） |
| **OK**（松开时） | 正在播＝暂停；正在缓冲/画面停住＝重新加载；已结束＝重新播放。执行完会自动收起控制栏 |
| **菜单键** | 显示 / 收起控制栏（全屏时按菜单键可以直接切换） |
| 遥控器上的**快进 / 快退**键 | 与左右键等价（走系统媒体键通道） |

### 5.5 直播

| 按什么 | 会发生什么 |
|---|---|
| **上 / 下** | **按下就切**，不用等松手：上一个 / 下一个频道。「播放设置 → 反转」打开后上下对调（上＝下一个频道） |
| **左 / 右** | **松开才生效**：这一路是直播流就切上一条 / 下一条线路；如果它其实是点播流，就变成快退 / 快进（可用「反转」「跨类」「换源」在控制栏里进一步调） |
| **数字键** | 直接输入频道号。**最多 4 位**，停手 **2 秒**后自动跳过去（数字显示在屏幕上） |
| **OK** | 收起信息栏 + 调出控制栏 |
| **菜单键 / 长按 OK** | 调出控制栏（换源、换线路、画面比例都在这里） |
| **断开直播源后怎么回来** | 直播页按返回回首页；再进直播会重新连 |

### 5.6 控制条上到底有哪几个按钮

这是老人最容易"找不到按钮"的地方，所以照实际顺序列一遍（从左到右）。按钮**不是每个都出现**——节目不支持就自动隐藏。

**点播控制条：**

| 按钮 | 干什么 | 什么时候才出现 |
|---|---|---|
| 下集 / 上集 | 换集 | 有多集时 |
| 解析 | 切换网页解析线路 | 站长配置了网页解析才出现 |
| EXO | 切到内置 EXO 播放器 | 一般都在 |
| 硬解 | 硬解 / 软解切换 | 一般都在 |
| 刷新 | 重新加载当前集 | 一般都在 |
| 重播 | 从头再放 | 一般都在 |
| 循环 | 单集循环开 / 关 | 一般都在 |
| 倍速 | 设置默认播放倍速（上下调） | 一般都在 |
| 原始 | 画面比例回「原始」 | 一般都在 |
| 字幕 / 音轨 / 视轨 | 选字幕、选配音、选清晰度 | 片源带多条轨道时 |
| 弹幕 | 弹幕开关与设置 | 配置了弹幕源才出现 |
| 片头 / 片尾 | 一键跳过 | 片源标注了片头片尾时间 |

**直播控制条：**

| 按钮 | 干什么 |
|---|---|
| 配置 | 打开直播源配置 |
| 播放 / 暂停 | 暂停继续 |
| 线路 | 换同一频道的其它线路 |
| EXO | 切到内置 EXO 播放器 |
| 硬解 | 硬解 / 软解切换 |
| 倍速 | 调整播放倍速 |
| 原始 | 画面比例回「原始」 |
| 字幕 / 音轨 / 视轨 | 选字幕、配音、清晰度 |
| **反转** | 上下键互换（上＝下一个频道） |
| **跨类** | 允许在「点播流 / 直播流」的最外层分类之间一起换台 |
| **换源** | 换到别的直播源 |

### 5.7 设置页 / 长辈设置

- 上下移动，OK 进入下一层或直接执行；带 `›` 箭头的行表示还能再进去一层；
- **字号大小、海报尺寸**是"按一下换一档"，循环着走（字号 5 档、海报尺寸 4 档），觉得合适就停；
- 开关类（自动全屏、开机看上次影片、按键音……）按 OK 就是切换。

### 5.8 搜索 / 填地址（软键盘）

键盘是**大按键**、**6 列**排布，方向键移动、OK 输入。第一排是 6 个图标键，其余是字母 / 数字键：

- **图标键（从左到右）**：**推送**（打开二维码页，手机扫码把文字发到电视）、**左移**光标、**右移**光标、**退格**、**搜索**（放大镜）、**中/英**（字母 ↔ 注音 ㄅㄆㄇ 两种键盘）；
- **长按退格键 = 整行清空**（一个个删太慢的时候用）；
- 一个弹窗里有多个输入框时，在输入框上**按上下直接跳到另一个输入框**，不用一路按回来；
- 嫌遥控器打字麻烦：弹窗里有二维码，手机扫一下在手机上填，电视这边会自动填好。

### 5.9 ③④ 专有：应用页

- 顶部三档：**全部 / 我的应用 / 已隐藏（n）**；第一格固定是「系统设置」；
- **OK = 打开这个应用**；
- **长按 OK 约 1 秒 = 进入管理模式**：下方出现「放到最前 / 取消置顶」「隐藏起来 / 显示出来」「卸载应用」「应用信息」。管理模式下单击应用只是"换个管理目标"，不会跳走；
- 被隐藏的应用要按顶部「已隐藏」才找得回来；系统应用不给「卸载」入口。

### 5.10 ③④ 专有：启动与桌面体检页

- 四行对应四件事，右侧写着状态（各状态的对照见第四节 4.1）；
- 上下选一行、OK 跳到系统对应的设置页；右下角「一键检查并修复」会按顺序只做**下一件没做的事**；
- **④ 守护版**的第四行固定显示「本版本未声明桌面，不能设为默认桌面」（整行变淡），点它只提示这一句、不会跳到一个找不到自己的页面；「一键检查并修复」也会自动跳过这一项——它不声明桌面，跳过去是打不开的死路。

### 5.11 按键音

默认开着：焦点移动一声「嘀」，按确定一声确认音，出错另有一种提示音。嫌吵就去「长辈设置 → 按键音」关掉（只影响电视版，手机版没有这一项）。

## 六、第一次使用

1. **装上并打开**。第一次进来首页会提示"**未配置数据源，按上方「设置」添加**"——这是正常的，因为还没有片源。这张提示卡是**不能点的**，要用功能行里的「设置」。
2. **添加片源**：点「设置」→「**点播源**」→ 弹窗里填两项：
   - **名称**：随便起一个，比如"常用"（也可以不填）
   - **配置**：粘贴你拿到的片源接口地址

   填完按「确定」，等它把配置下载完。
   > 用遥控器打字很麻烦：电视上弹窗里有二维码，**用手机扫一下**就能在手机上填，电视这边输入框会自动填上，你再按「确定」。
   >
   > 首页功能行里的「推送」是同一套东西：电视上显示一个二维码和一个局域网地址，手机扫码打开那个网页，就能把文字/链接推到电视上（电视这一端只是显示，不需要按任何按钮）。
3. **回首页**：按「返回」，这时应该能看到「推荐」和各个分类了。
4. **调字号**（仅电视版）：进「设置 → 长辈设置 → 字号大小」，按一下换一档，觉得够大就停（屏幕小的电视别用"极大"）。
5. **锁定片源**（推荐）：进「设置 → 长辈设置 → 一键锁定」，选好数据源，按最下面的「一键锁定」。之后老人开机只要按「播放」就行。

## 七、长辈设置里有哪些开关

电视版顺序如下（**③④ 多一项「启动与桌面体检」**，位置在「开机进直播」之后）：

| 项目 | ② 标准电视 | ③④ | ① 手机 | 干什么用的 |
|---|---|---|---|---|
| 一键锁定 | ✅ | ✅ | ✅ | 锁定数据源 / 自动换源 / 搜索优先源 / 直播源，防止老人误操作换掉 |
| 站源管理 | ✅ | ✅ | ✅ | 把用不上的数据源停掉（停用后不显示在首页和搜索中），可「只看停用」、「全部停用」 |
| 字号大小 | ✅ | ✅ | — | 5 档：标准 / 大 / 特大 / 超大 / 极大（手机跟随系统字号） |
| 海报尺寸 | ✅ | ✅ | ✅ | 4 档：小 / 中 / 大 / 特大，控制一屏显示几个封面 |
| 点播自动全屏 | ✅ 默认开 | ✅ 默认开 | ✅ 默认开 | 关掉后要先选集才会全屏 |
| **开机看上次影片** | ✅ 默认关 | ✅ 默认关 | ✅ 默认关 | 打开后：开机（冷启动）直接接着上次那一集播。与下一项**互斥** |
| **开机进直播** | ✅ 默认关 | ✅ 默认关 | ✅ 默认关 | 打开后：开机（冷启动）直接进直播页。与上一项**互斥**——开这个会把「开机看上次影片」自动关掉，反之亦然（后开的赢） |
| **启动与桌面体检** | — | ✅ | — | 开机自启 / 后台白名单 / 按主页键回来看电视 / 设为默认桌面，四件事一页检查并修复 |
| 首页快速搜索 | ✅ 默认关 | ✅ 默认关 | ✅ 默认关 | 打开后点首页内容会先去搜同名（多个片源一起找）；关着直接进详情页 |
| **屏蔽内容提示** | ✅ 默认开 | ✅ 默认开 | ✅ 默认开 | 屏蔽站源公告、解析来源、推送同步、弹幕/字幕搜索这类"内容侧"提示；「已复制」「锁定成功」等操作反馈照常 |
| 按键音 | ✅ 默认开 | ✅ 默认开 | — | 按键时的提示音 |
| 恢复默认 | ✅ | ✅ | ✅ | 只恢复这一页的设置。确认框里写明：**数据源、收藏、历史保留**（③④ 会把体检里的开关也恢复成默认） |
| 底部导航直播入口 | — | — | ✅ | 手机上是否在底部显示「直播」这一栏 |

> 「开机看上次影片」和「开机进直播」**只能选一个**，因为两者抢的是同一个位置：开机后第一屏。默认两个都关，开机就是普通的首页。

「长辈设置」的位置：电视版在设置页**最上面**；手机版在「点播源 / 直播源 / 壁纸源」**下面**。

## 八、播放时找不到能看的怎么办

软件会**自己想办法**，老人不用操作：

1. 先自动换这条片源的**其它线路**（按线路好坏挑）；
2. 还不行，就自动换到**其它数据源**的同名影片；
3. 手动点「换源」时，会提示"**正在查找其他站源…**"；
4. 实在找不到，才提示"**未找到同片的其他站源**"。

> 配合「站源管理」把老人压根打不开的源（比如网盘类）停掉，自动换源就只在能看的那些源里找，命中率更高。

## 十、常见问题

**Q：首页提示"未配置数据源"？**
A：还没添加片源。点上面的「设置」→「点播源」，填名称和配置地址。

**Q：整页只有一张提示卡，点它没反应？**
A：那张卡是说明用的，不能点。用功能行的「设置」进去添加片源（③④ 是标题区右上角的齿轮）。

**Q：按返回键怎么退不出去？**
A：首页要 **4 秒内连按三次**才退出（第一下会提示「再按两次返回键退出」，后两下不提示）。在别的页面按返回只是回首页，本来就不会退出。另外，如果 **③ 桌面版**已经被设成「默认桌面」，首页按返回键是**没有动作**的——这是故意的，和电视自带桌面一致。

**Q：播放时按返回，怎么先回到全屏画面了？**
A：返回是逐级退：先收起控制栏 → 再退出全屏 → 最后回首页。连按几下就到首页了。

**Q：提示"数据源已锁定，想换请先解锁"？**
A：锁定功能在起作用。进「设置 → 长辈设置 → 一键锁定 → 解锁」就可以了。

**Q：电视打开一直停在"连接网络中…"？**
A：先看电视/盒子有没有联网。没网时它会停在这一屏等，网络恢复后自动继续。

**Q：首页显示"连接失败，联网后自动重试"？**
A：数据源这次没取到内容（网络抖动或那个源暂时不通），不是软件坏了。网络好了会自动重试；手机上旁边还有「重新加载」按钮可以手动再来一次。

**Q：字太大，有的地方显示不全？**
A：把字号调小一档。屏幕小的电视建议不要用"极大"。

**Q：换壁纸 / 切主题色 / 改字号之后，首页要等一会儿才出来？**
A：6.0.4 之前的版本会整页重载（连数据源一起重新下载），现在不重载数据源了，只重画/重建界面。电视版重建后首页内容会重拉一次（约 1~2 秒）；手机版重建后首页和「推荐」会自动重新加载，不会停在旧数据。如果一直转圈不出来，多半是那个数据源本身就慢，按上面"连接失败"那条处理。

**Q：点「恢复默认」，收藏和历史会丢吗？**
A：不会。它只恢复这一页上的设置项，数据源、收藏、历史都保留。

**Q：为什么软件里什么内容都没有？**
A：这个软件本身不含任何影视内容，内容全部来自你自己添加的配置地址。

**Q：安装时提示"应用未安装"？**
A：先换另一个位数的包（同目录里的 `armeabi_v7a`）试试；也可能是设备里已经装过本软件的其它包（四个包内部包名相同，装 ③ 之前必须先卸掉 ④，反之亦然），**先卸载再装**。卸载不会丢数据源/收藏/历史，重装后还在。

**Q：装的是 ③④，但开机没有自动打开？**
A：①看「长辈设置 → 启动与桌面体检」第一项是不是"已关闭"；②部分电视（TCL / 雷鸟等）在「安全中心 / 权限管理」里默认禁止第三方应用自启，要点「允许」；③有些电视「关机」其实是待机，不会触发开机启动，得真正断电再上电；④③ 已设为默认桌面时，这一项会显示"已经是电视默认桌面了"，那是正常的（桌面本身就开机自启）。

**Q：③④ 的应用页是空的 / 少了很多应用？**
A：应用页只列**有桌面图标**的应用（能点开的）。安卓 11 以后的电视对"能看到哪些应用"有限制，本软件只申请了"有启动入口的应用"这一项，没有申请"读取全部应用列表"；如果页面完全空白，通常是系统把包查询权限拦了，重启一次软件即可。

**Q：应用页里长按没有反应？**
A：遥控器上按住「确定 / OK」键别松，大约 1 秒进入管理。管理是"两步式"的：先选要做什么，再确认；隐藏起来的应用要按顶部「已隐藏」才找得回来。

**Q：体检页某一项一直显示"需要设置"？**
A：有些电视把对应的系统页裁掉了，跳不过去。体检页会提示"这台电视不支持直接跳转，请到系统设置里改"，按提示自己找那一项即可，不影响其它功能。

**Q：④ 守护版的体检页第四行写「本版本未声明桌面，不能设为默认桌面」，是坏了吗？**
A：不是。④ 就是这么设计的——它**从不声明自己是桌面**，所以永远不会抢你的电视桌面、也不会弹「选择桌面」框。真想让看电视直接当桌面，请卸载后装 **③ 桌面版**。④ 的作用是靠无障碍服务「一看见桌面就切回来看电视」，效果接近但不改桌面归属。

**Q：体检页第三行写「已开启但没在运行」？**
A：权限给了，但服务被系统掐掉了（有些电视清理后台很激进）。在这一行按 OK，会显示"正在重新连接…请稍等几秒"自愈；实在不行按「一键检查并修复」再走一遍。

**Q：把「开机看上次影片」和「开机进直播」都打开了，为什么只剩一个？**
A：这两个开关抢的是同一个位置（开机后第一屏），所以是**互斥**的：后打开的那个会把另一个自动关掉。想让老人开机就接着看剧 → 开「开机看上次影片」；想让老人开机就有台可看 → 开「开机进直播」。

**Q：推送页只有一个二维码和一个地址，没有按钮，怎么用？**
A：这一页本来就是"给手机看"的：用手机扫二维码（或者在手机浏览器里输入那个地址），在手机网页里把文字或链接推过去，电视就会收到。电视这一端不需要按任何按钮，按「返回」退出即可。

**Q：手机版切了主题色 / 改了设置，首页内容会变吗？**
A：会重新加载一次（这正是为了让新设置后的内容立刻生效）。配置和源列表不会重新下载，所以很快。

**Q：四个包能共用同一份数据源配置吗？**
A：可以。配置和收藏/历史都存在本机，同签名覆盖安装不会丢；卸载重装（比如 ④ 换 ③）才会清掉，建议先在「设置 → 备份」导出一份。

### 13.2 构建

- 环境：JDK 21、Android SDK（compileSdk 37）、minSdk 24
- 编译前在根目录建 `local.properties`，填 `sdk.dir` 和签名四项（`storeFile` / `keyAlias` / `storePassword` / `keyPassword`）
- 出包：两个分支**各出两个变体**（`main` 树只有 `mobile` / `leanback` 两个 flavor，`autostart` 树只有 `leanbackHome` / `leanbackGuard` 两个 flavor，四者不可能在同一次构建里同时出现）：

```bash
# main 分支（标准树）
./gradlew :app:assembleMobileRelease          # ① 手机版      → dist/mobile-standard/
./gradlew :app:assembleLeanbackRelease        # ② 标准电视版  → dist/leanback-standard/

# autostart 分支（自启树）
./gradlew :app:assembleLeanbackHomeRelease    # ③ 桌面电视版  → dist/leanback-home/
./gradlew :app:assembleLeanbackGuardRelease   # ④ 守护电视版  → dist/leanback-guard/
```

- 产物落在 `../dist/<产物目录>/`（**四个语义子目录**，每个目录平铺 2 个 ABI 的 APK + `MD5.txt`）
- ✅ `MD5.txt` 由构建**自动生成**（`buildSrc` 里 `AbiApkPackaging` 的 `doLast` + 独立任务 `writeDistMd5`）——**不要手写**，手写版一构建就过期
- 播放内核等预编译库已在 `app/libs/` 里一并入库，克隆后无需额外下载
- ⚠️ 改了 `app/src/main/` 下被 ① 实际调用的东西（`Setting`、`ImgUtil`、`Clock` 等）**必须把 ① 也重建**，否则手机包是旧的
- 两棵树构建时 `EXT_BUILD_DIR` 必须各用各的，否则中间产物会串（资源数虚高、异树布局混入）

### 13.3 维护两个分支

本地有两棵开发树（`FongMi-TV/repo` = 标准树出 ①②、`FongMi-TV/repo-autostart` = 自启树出 ③④），发布时用脚本同步到本仓库的两个分支：

```bash
python sync-to-github.py --variant main          # 标准树 → main（① 手机 + ② 标准电视）
python sync-to-github.py --variant autostart     # 自启树 → autostart（③ 桌面 + ④ 守护）
python sync-to-github.py --dry-run               # 只看会改什么
```

`README.md` / `CHANGELOG.md` / `NOTICE.md` / `.gitattributes` / `.gitignore` / `gradle.properties` 属于**人工维护**，任何一侧的源码都不会覆盖它们——所以四个产物的说明只需在这里写一次。

- 配置格式见 [docs/CONFIG.md](docs/CONFIG.md)；上游原始开发者文档见 [README.upstream.md](README.upstream.md)；许可与第三方组件见 [NOTICE.md](NOTICE.md)
