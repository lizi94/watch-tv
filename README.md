# 长辈版看电视 App（电视盒子 / 手机都能装）

这是一个给**家里老人**用的看电视软件。原版功能很强，但按钮小、字也小、选项多，老人容易按错、找不到回来的路。这个版本把界面重做了一遍：**字大、按钮大、能用遥控器少按键操作、按错也不会迷路**。

改造重点在**电视版**（老人主要用电视看）。手机版保留原版触摸操作，把能共用的设置项补齐了——所以**两个版本功能不完全一样**，下面表格里都标清楚了。

> 本软件**不带任何电影、电视剧、直播内容**。片源要靠你自己添加一个「配置」地址才有内容。

---

## 一、两个版本，先选一个

从 v6 开始，仓库有**两个版本**，功能差在电视端的两件事上，其余完全相同：

| | **标准版** | **自启版** |
|---|---|---|
| 在哪 | `main` 分支 | `autostart` 分支 |
| 下载 | [Releases v6.0.3](../../releases/tag/v6.0.3) | [Releases v6.0.4](../../releases/tag/v6.0.4) |
| 版本号 | 6.0.3（603） | 6.0.4（604） |
| **开机自动打开软件** | — 没有 | ✅ 有（默认开，可在长辈设置里关） |
| **接管 Home 键**（按主页键自动切回软件） | — 没有 | ✅ 有（默认开，可在长辈设置里关） |
| 后台保活（通知监听） | — | ✅ 有（需在系统里授权「通知使用权」） |
| 申请无障碍权限 | ❌ 不申请 | ✅ 需要（仅用于判断"电视桌面回到前台"） |
| 装好后要不要额外设置 | 不用，直接能用 | 要开一个无障碍开关，见第四节 |

**怎么选：**

- **老人自己开电视、不会自己找到软件** → 装**自启版**。开机就自动进软件，按主页键跑掉了也会自己回来，这才是「像数字电视机顶盒一样」的体验。
- **只是自己/家人偶尔用，或者不想给 App 无障碍权限** → 装**标准版**。少一个常驻服务，最干净。

两个版本**不能同时装**（包名相同），换版本前先卸载。两版的版本号故意不同（603 / 604），就是为了让你一眼看出装的是哪一版。

## 三、装哪个包？

**先按第一节选版本，再按「设备 + 位数」选包**——每个 Release 里都是同样 4 个文件，只是版本不同：

| 你的设备 | 装这个 |
|---|---|
| 电视 / 电视盒子 | `leanback-arm64_v8a.apk` |
| 电视 / 盒子只支持 32 位 | `leanback-armeabi_v7a.apk` |
| 手机 / 平板 | `mobile-arm64_v8a.apk` |
| 手机 / 平板只支持 32 位 | `mobile-armeabi_v7a.apk` |

**不确定装哪个？** 先装带 `arm64_v8a` 的那个；提示"应用未安装"或打开就闪退，就换 `armeabi_v7a` 再试一次。两个都装不上，说明设备太老，跑不起这个版本。

> 想知道电视是 32 位还是 64 位：装错时会提示"应用未安装"，换另一个就行；或用 adb 看 `getprop ro.product.cpu.abilist`，出现 `arm64-v8a` 就是 64 位。

安装包在对应 Release 里下载，Release 说明里附了每个包的 MD5，下载后可以核对。

## 四、自启版额外要做的两步

标准版跳过这一节。自启版装上后**开机自启**能直接用；**接管 Home 键**需要你手动开一次无障碍权限（安卓的安全规定，任何 App 都不能自己开）。

### 4.1 打开「接管 Home 键」

1. 电视上依次进入 **设置 → 长辈设置 → 接管 Home 键**，按一下「确定」，它会告诉你去哪里开；
2. 到系统里找：**设置 → 无障碍 / 辅助功能 → 已下载的服务 / 已安装的应用**，找到「**看电视 · 桌面守护**」，打开它，确认「允许」；
3. 回到软件，按一下遥控器的**主页键**——大约 1~2 秒后应该自动切回软件，说明生效了。

> 找不到入口的电视：不同品牌叫法不一样，常见的是「无障碍」「辅助功能」「更多设置 → 无障碍」。也可以在系统设置里搜「无障碍」。
>
> TCL / 雷鸟电视如果把这个服务藏起来：去「安全中心 / 权限管理」里放行一次，再回来打开。

### 4.2（可选）授权「通知使用权」

这一步**不做也能用**，作用是让系统不那么容易把软件从后台清掉（部分电视看完片子回到桌面后过一会儿又被杀掉，就是缺这个）：

**设置 → 通知 → 通知使用权 / 通知使用权管理**，找到「看电视」，打开。

### 4.3 这两项怎么关掉

- **只想让主页键恢复正常**：长辈设置里把「接管 Home 键」关掉即可（不用去系统里停服务）；
- **想彻底收回权限**：系统设置 → 无障碍 → 「看电视 · 桌面守护」关掉；
- **不想开机自动打开**：长辈设置里把「开机自启动」关掉。

### 4.4 装了自启版可能遇到的现象

| 现象 | 说明 |
|---|---|
| 按主页键时弹出「选择主屏幕应用」的选择框 | 因为自启版声明了自己可以当桌面。选「看电视」+「始终」最省事；不想让它当桌面就选你原来的桌面，软件照样能靠无障碍切回来。 |
| 从电视桌面进别的 App（比如相册），会被立刻拉回来 | 这是「接管 Home 键」的代价——它只管"桌面一出现就切回"，不区分你是按主页键回去还是开机就在桌面。临时要用别的 App，先把「接管 Home 键」关掉。 |
| 开机后仍要等十几秒才自动出现 | 部分电视（如 TCL）会把第三方 App 的启动压到开机后几十秒。实测从"桌面出来再干等约 2 分钟"缩短到"约 30 秒"，剩下的卡在系统侧，App 端改不动。 |

> 桌面守护只做一件事：**看当前在前台的是不是电视自带桌面**（只比对包名，不读屏幕内容、不记录任何操作）。无障碍配置里已明确关闭「读取窗口内容」。

## 五、第一次使用

1. **装上并打开**。第一次进来首页会提示"**还没有设置数据源，请按上面的「设置」按钮添加**"——这是正常的，因为还没有片源。这张提示卡是**不能点的**，要用功能行里的「设置」。
2. **添加片源**：点「设置」→「**点播源**」→ 弹窗里填两项：
   - **名称**：随便起一个，比如"常用"（也可以不填）
   - **配置**：粘贴你拿到的片源接口地址

   填完按「确定」，等它把配置下载完。
   > 用遥控器打字很麻烦：电视上弹窗里有二维码，**用手机扫一下**就能在手机上填，电视这边输入框会自动填上，你再按「确定」。
3. **回首页**：按「返回」，这时应该能看到「推荐」和各个分类了。
4. **调字号**（仅电视版）：进「设置 → 长辈设置 → 字号大小」，按一下换一档，觉得够大就停（屏幕小的电视别用"极大"）。
5. **锁定片源**（推荐）：进「设置 → 长辈设置 → 一键锁定」，选好数据源，按最下面的「一键锁定」。之后老人开机只要按「播放」就行。

## 六、长辈设置里有哪些开关

电视版顺序如下（**自启版多两项**，位置在「点播退出自动续播」之后）：

| 项目 | 标准版 | 自启版 | 手机版 | 干什么用的 |
|---|---|---|---|---|
| 一键锁定 | ✅ | ✅ | ✅ | 锁定数据源 / 自动换源 / 搜索优先源 / 直播源，防止老人误操作换掉 |
| 站源管理 | ✅ | ✅ | ✅ | 把用不上的数据源停掉（停用后不显示在首页和搜索中），可「只看停用」、「全部停用」 |
| 字号大小 | ✅ | ✅ | — | 5 档：标准 / 大 / 特大 / 超大 / 极大 |
| 图片尺寸 | ✅ | ✅ | ✅ | 4 档：小 / 中 / 大 / 特大，控制一屏显示几个封面 |
| 点播自动全屏 | ✅ 默认开 | ✅ 默认开 | ✅ 默认开 | 关掉后要先选集才会全屏 |
| 点播退出自动续播 | ✅ 默认开 | ✅ 默认开 | ✅ 默认开 | 关掉后下次从头播放，不接着上次看 |
| **开机自启动** | — | ✅ 默认开 | — | 电视开机后自动打开本软件；关掉就停在电视原桌面 |
| **接管 Home 键** | — | ✅ 默认开 | — | 按主页键回到电视桌面时自动切回本软件 |
| 首页快速搜索 | ✅ 默认关 | ✅ 默认关 | ✅ 默认关 | 打开后点首页内容会先去搜同名（多个片源一起找）；关着直接进详情页 |
| 按键音 | ✅ 默认开 | ✅ 默认开 | — | 按键时的提示音 |
| 恢复默认设置 | ✅ | ✅ | ✅ | 只恢复这一页的设置。确认框里写明：**数据源、收藏、观看记录都会保留**（自启版会把上面两个开关也恢复成"开"） |
| 底部导航直播入口 | — | — | ✅ | 手机上是否在底部显示「直播」这一栏 |

「长辈设置」的位置：电视版在设置页**最上面**；手机版在「点播源 / 直播源 / 壁纸源」**下面**。

## 七、播放时找不到能看的怎么办

软件会**自己想办法**，老人不用操作：

1. 先自动换这条片源的**其它线路**（按线路好坏挑）；
2. 还不行，就自动换到**其它数据源**的同名影片；
3. 手动点「换源」时，会提示"**正在查找其它站源……**"；
4. 实在找不到，才提示"**未找到同一影片的其他站源**"。

> 配合「站源管理」把老人压根打不开的源（比如网盘类）停掉，自动换源就只在能看的那些源里找，命中率更高。

## 九、常见问题

**Q：首页提示"还没有设置数据源"？**
A：还没添加片源。点上面的「设置」→「点播源」，填名称和配置地址。

**Q：整页只有一张提示卡，点它没反应？**
A：那张卡是说明用的，不能点。用上方功能行的「设置」进去添加片源。

**Q：提示"数据源已锁定，如需更换请先解锁"？**
A：锁定功能在起作用。进「设置 → 长辈设置 → 一键锁定 → 解锁」就可以了。

**Q：电视打开一直停在"正在连接网络…"？**
A：先看电视/盒子有没有联网。没网时它会停在这一屏等，网络恢复后自动继续。

**Q：字太大，有的地方显示不全？**
A：把字号调小一档。屏幕小的电视建议不要用"极大"。

**Q：恢复默认设置，收藏和历史会丢吗？**
A：不会。它只恢复这一页上的设置项，数据源、收藏、观看记录都保留。

**Q：为什么软件里什么内容都没有？**
A：这个软件本身不含任何影视内容，内容全部来自你自己添加的配置地址。

**Q：安装时提示"应用未安装"？**
A：换另一个位数的包（`armeabi_v7a`）试试；也可能设备里已经装过同一个软件的其他版本（比如先装了标准版又想换自启版），**先卸载再装**。

**Q：装的是自启版，但开机没有自动打开？**
A：①看「长辈设置 → 开机自启动」是不是被关了；②部分电视（TCL / 雷鸟等）在「安全中心 / 权限管理」里默认禁止第三方应用自启，要点「允许」；③有些电视「关机」其实是待机，不会触发开机启动，得真正断电再上电。

**Q：装的是自启版，按主页键回不到电视桌面了？**
A：这就是「接管 Home 键」。想在桌面待着，去「长辈设置 → 接管 Home 键」关掉；想恢复默认桌面，在系统「设置 → 应用 → 默认应用 → 主屏幕应用」里改回去。

**Q：两个版本能用同一个数据源配置吗？**
A：可以。配置和收藏/历史都存在本机，同签名覆盖安装不会丢。

### 12.2 构建

- 环境：JDK 21、Android SDK（compileSdk 37）、minSdk 24
- 编译前在根目录建 `local.properties`，填 `sdk.dir` 和签名四项（`storeFile` / `keyAlias` / `storePassword` / `keyPassword`）
- 出包：`./gradlew :app:assembleLeanbackRelease`（电视版）或 `:app:assembleMobileRelease`（手机版）
- 播放内核等预编译库已在 `app/libs/` 里一并入库，克隆后无需额外下载
- ⚠️ 改了 `app/src/main/` 下的东西（`Setting`、`ImgUtil`、`Clock` 等被手机版共用）**必须双端都重建**，否则手机包是旧的
- 产物默认落在 `../dist`；`MD5.txt` 由构建自动生成，单独刷新：`./gradlew writeDistMd5`

### 12.3 维护两个分支

本地有两棵开发树（`FongMi-TV/repo` = 标准版、`FongMi-TV/repo-autostart` = 自启版），发布时用脚本同步到本仓库的两个分支：

```bash
python sync-to-github.py --variant main          # 标准版 → main
python sync-to-github.py --variant autostart     # 自启版 → autostart
python sync-to-github.py --dry-run               # 只看会改什么
```
