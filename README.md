# 长辈版看电视 App（电视盒子 / 手机都能装）

这是一个给**家里老人**用的看电视软件。原版功能很强，但按钮小、字也小、选项多，老人容易按错、找不到回来的路。这个版本把界面重做了一遍：**字大、按钮大、能用遥控器少按键操作、按错也不会迷路**。

改造重点在**电视版**（老人主要用电视看）。手机版保留原版触摸操作，把能共用的设置项补齐了——所以**两个版本功能不完全一样**，下面表格里都标清楚了。

> 本软件**不带任何电影、电视剧、直播内容**。片源要靠你自己添加一个「配置」地址才有内容。

---

## 一、两个版本，先选一个

从 v6 开始，仓库有**两个版本**，功能差在电视端的几件事上，其余完全相同：

| | **标准版** | **自启版** |
|---|---|---|
| 在哪 | `main` 分支 | `autostart` 分支 |
| 下载 | [Releases v6.4.2](../../releases/tag/v6.4.2) | [Releases v6.4.3](../../releases/tag/v6.4.3) |
| 版本号 | 6.4.2（642） | 6.4.3（643） |
| **开机自动打开软件** | — 没有 | ✅ 有（体检页里可关） |
| **接管 Home 键**（按主页键自动切回软件） | — 没有 | ✅ 有（需授权一次无障碍） |
| **「应用」页**（进电视上其它 App / 置顶常用 / 隐藏无关的） | — 没有 | ✅ 有 |
| **「启动与桌面体检」页**（四步一键检查并修复） | — 没有 | ✅ 有 |
| 后台保活（通知监听） | — | ✅ 有（需授权「通知使用权」，不授权也能用） |
| 申请无障碍权限 | ❌ 不申请 | ✅ 需要（只用于判断"电视桌面回到前台"） |
| 装好后要不要额外设置 | 不用，直接能用 | 打开「长辈设置 → 启动与桌面体检」按一遍 |

**怎么选：**

- **老人自己开电视、不会自己找到软件** → 装**自启版**。开机就自动进软件，按主页键跑掉了也会自己回来，这才是「像数字电视机顶盒一样」的体验。
- **只是自己/家人偶尔用，或者不想给 App 无障碍权限** → 装**标准版**。少一个常驻服务，最干净。

两个版本**不能同时装**（包名相同），换版本前先卸载。两版的版本号恒差 1、标准版恒比自启版低 1（642 / 643），就是为了让你一眼看出装的是哪一版。

> 自启版**不会把自己声明成"系统桌面"**，所以按主页键时不会弹「选择桌面」框，也不会被误设成默认桌面。想让它当桌面，到体检页里手动设（部分电视不支持）。

- **手机版**：用列表**右下角的圆形悬浮按钮**——往下翻时它是「返回顶部」，往上翻时它变成「筛选」，点它就弹出筛选面板（分类没有筛选条件时这个按钮不出现）。

## 三、装哪个包？

**先按第一节选版本，再按「设备 + 位数」选包**——每个 Release 里都是同样 4 个文件，只是版本不同：

| 你的设备 | 装这个 |
|---|---|
| 电视 / 电视盒子 | `leanback-arm64_v8a.apk` |
| 电视 / 盒子只支持 32 位 | `leanback-armeabi_v7a.apk` |
| 手机 / 平板 | `mobile-arm64_v8a.apk` |
| 手机 / 平板只支持 32 位 | `mobile-armeabi_v7a.apk` |

**不确定装哪个？** 先装带 `arm64_v8a` 的那个；提示"应用未安装"或打开就闪退，就换 `armeabi_v7a` 再试一次。两个都装不上，说明设备太老，跑不起这个版本。

> 想知道电视是 32 位还是 64 位：装错时会提示"应用未安装"，换另一个就行；或用 adb 看 `getprop ro.product.cpu.abilist`，出现 `arm64-v8a` 就是 64 位。

安装包在对应 Release 里下载，Release 说明里附了每个包的 MD5，下载后可以核对。

## 四、自启版：装好后先做一次体检

标准版跳过这一节。自启版装上就能用，但**建议打开「设置 → 长辈设置 → 启动与桌面体检」按一遍**——那里把自启版需要系统配合的四件事集中在一页里，点右下角「一键检查并修复」会挨个跳到系统对应的设置页。

### 4.1 体检页上的四件事

| 检查项 | 做什么 | 为什么需要 |
|---|---|---|
| **开机就打开看电视** | 让软件开机后自动出现 | 老人不会自己去找软件 |
| **让电视别把看电视关掉** | 把本软件加进"允许后台运行 / 电池不优化"白名单 | 有些电视看完片子回到桌面后过一会儿就把软件杀了 |
| **按主页键回到看电视** | 打开无障碍里的「看电视 · 桌面守护」 | 安卓规定任何 App 都不能自己开，只能你手动开一次 |
| **把看电视设为电视主页**（部分电视不支持） | 让本软件直接当桌面 | 想彻底替代电视自带桌面时用；不支持就改用上一项 |

每行右侧会写状态：**已设置** / **需要设置** / **已关闭** / **已由电视主页接管，不用开**。四件都齐了会显示"都设置好了"。某台电视跳不过去时，会提示"这台电视不支持直接跳转，请到系统设置里改"。

### 4.2 手动打开「按主页键回到看电视」

体检页跳不过去时，自己找：

1. 电视上依次进入 **设置 → 无障碍 / 辅助功能 → 已下载的服务 / 已安装的应用**，找到「**看电视 · 桌面守护**」，打开它，确认「允许」；
2. 回到软件，按一下遥控器的**主页键**——大约 1~2 秒后应该自动切回软件，说明生效了。

> 不同品牌叫法不一样，常见的是「无障碍」「辅助功能」「更多设置 → 无障碍」。也可以在系统设置里搜「无障碍」。
>
> TCL / 雷鸟电视如果把这个服务藏起来：去「安全中心 / 权限管理」里放行一次，再回来打开。

### 4.3（可选）授权「通知使用权」

这一步**不做也能用**，作用是让系统不那么容易把软件从后台清掉：

**设置 → 通知 → 通知使用权 / 通知使用权管理**，找到「看电视」，打开。这个服务不读取任何通知内容。

### 4.4 这些怎么关掉

- **只想让主页键恢复正常**：体检页里把「按主页键回到看电视」对应的权限关掉（或去系统无障碍里关「看电视 · 桌面守护」）；
- **不想开机自动打开**：长辈设置里把开机自启关掉（体检页第一项也会变成"已关闭"）；
- **想恢复到电视自带桌面**：应用页顶部第一格或体检页的「换回电视自带的主页」。

### 4.5 装了自启版可能遇到的现象

| 现象 | 说明 |
|---|---|
| 从电视桌面进别的 App（比如相册），会被立刻拉回来 | 这是「按主页键回到看电视」的代价——它只管"桌面一出现就切回"，不区分你是按主页键回去还是开机就在桌面。临时要用别的 App，先在电视桌面连按两次主页键（放行 3 分钟），或者把该项关掉。 |
| 按主页键后被拉回，但想留在桌面待一会儿 | 同上：桌面出现后 10 秒内**连按两次主页键**即放行 3 分钟，期间系统应用（设置、相册等）都能正常用；再打开一次本软件立刻恢复接管。 |
| 开机后仍要等十几秒才自动出现 | 部分电视（如 TCL）会把第三方 App 的启动压到开机后几十秒。实测从"桌面出来再干等约 2 分钟"缩短到"约 10~30 秒"，剩下的卡在系统侧，App 端改不动。 |

> 桌面守护只做一件事：**看当前在前台的是不是电视自带桌面**（只比对包名，不读屏幕内容、不记录任何操作）。无障碍配置里已明确关闭「读取窗口内容」。

## 五、遥控器怎么按（每一页都写清楚）

这一节按**页面**讲遥控器上那几个键能干什么。手机版是触摸操作，不用看这节。

### 5.1 三条通用规则

| 键 | 作用 |
|---|---|
| **方向键** | 移动蓝色粗框（选中项）。每移动一格一声短促「嘀」（长辈设置里可关「按键音」） |
| **确定 / OK** | 执行；按下有一声确认音 |
| **返回** | **除首页外，任何页面按返回都回首页**，不会退出软件。播放页是逐级退：先收起控制栏 → 再退出全屏 → 最后才回首页 |

**首页的返回键只有一个含义**：**4 秒内连按三次**才退出。第一下会提示「再按两次返回键退出」，后面两下不再提示。
如果本软件已经被设成「电视主页」（默认桌面），首页按返回键**没有任何动作**——和电视自带桌面一致，因为退出去也会被系统立刻拉回来。

### 5.2 首页

| 想干什么 | 怎么按 |
|---|---|
| 打开某一格 | 焦点移到封面／按钮上按 OK |
| 换分类 | 焦点移到「推荐 / 分类」那一行，**左右移动就自动换**（不用按 OK）；按 OK 是"重新加载这个分类" |
| 搜同名影片 | 打开「首页快速搜索」开关后**单击封面** → 跳快搜跨源搜同名（所有站源统一受控）；开关关着时单击直接进详情页。**长按封面无功能**（防误触） |
| 删一条观看记录 | 在「最近观看」的封面上**长按 OK** → 进入删除模式 → **单击**要删的那条（会先问一句）。再长按 = 清空全部（也会问） |
| 筛选当前分类 | 按**菜单键**。推荐页、或这个分类本来没有筛选项时，只提示一句"当前分类没有筛选条件" |
| 进设置 | 标准版：功能行最右的「设置」；自启版：标题区右上角的齿轮 |

进首页时焦点**固定落在最上面那排大按钮上**（不落分类、不落标题），所以「一进来就迷路」从第一秒就避免了。

### 5.3 详情页（选集 / 换线路）

详情页从上到下依次是：影片信息 → 简介 / 收藏 / 换源 → **线路** → **选集** → **排序**。

- 方向键在几组之间移动，OK 选中；
- 选集是横向列表：左右移动，OK 直接播这一集。

### 5.4 播放中（点播）

| 按什么 | 会发生什么 |
|---|---|
| **左 / 右** | 快退 / 快进。按一下 10 秒，**按住不放会一直累加**，松开手才真正跳过去（不用再按 OK） |
| **上** | 调出控制栏。接近片头 / 片尾时会多出「片头」「片尾」按钮，一按直接跳过 |
| **长按上**（约 1 秒） | 临时倍速播放，**松开手就恢复原速** |
| **下** | 调出控制栏（同「上」） |
| **OK** | 暂停 / 继续；缓冲失败、画面停住时按 OK 是重新加载 |
| **菜单键** | 显示或收起控制栏 |
| 遥控器上的**快进 / 快退**键 | 与左右键等价 |

> 这些键在全屏播放、控制栏收起时才由播放页接管；控制栏开着的时候，方向键是在控制栏的按钮之间移动（正常导航）。

### 5.5 直播

| 按什么 | 会发生什么 |
|---|---|
| **上 / 下** | 上一个 / 下一个频道（「播放设置」里有「反转」开关，可以调成上=下一个） |
| **左 / 右** | 换线路：同一直播源的其它线路；如果这一路其实是点播流，就变成快退 / 快进 |
| **数字键** | 直接输入频道号，最多 4 位数字，停手 2 秒自动跳过去 |
| **OK** | 调出信息栏 + 控制栏 |
| **菜单键 / 长按 OK** | 调出控制栏（换源、换线路、画面比例都在这里） |

### 5.6 设置页 / 长辈设置

- 上下移动，OK 进入下一层或直接执行；带 › 箭头的行表示还能再进去一层；
- **字号大小、图片尺寸**是"按一下换一档"，循环着走，觉得合适就停；
- 开关类（自动全屏、自动续播、按键音……）按 OK 就是切换。

### 5.7 搜索 / 填地址（软键盘）

- 九宫格软键盘：方向键移动、OK 输入；
- **长按删除键 = 整行清空**（一个个删太慢的时候用）；
- 一个弹窗里有多个输入框时，在输入框上**按上下直接跳到另一个输入框**，不用一路按回来；
- 嫌遥控器打字麻烦：弹窗里有二维码，手机扫一下在手机上填，电视这边会自动填好。

### 5.8 自启版专有：应用页

- 顶部三档：**全部 / 我的应用 / 已隐藏（n）**；第一格固定是「系统设置」；
- **OK = 打开这个应用**；
- **长按 OK 约 1 秒 = 进入管理模式**：下方出现「放到最前 / 取消置顶」「隐藏起来 / 显示出来」「卸载应用」「应用信息」。管理模式下单击应用只是"换个管理目标"，不会跳走；
- 被隐藏的应用要按顶部「已隐藏」才找得回来；系统应用不给「卸载」入口。

### 5.9 自启版专有：启动与桌面体检页

- 四行对应四件事，右侧写着「已设置 / 需要设置 / 已关闭 / 已由电视主页接管，不用开」；
- 上下选一行、OK 跳到系统对应的设置页；右下角「一键检查并修复」会挨个走一遍。

### 5.10 按键音

默认开着：焦点移动一声「嘀」，按确定一声确认音。嫌吵就去「长辈设置 → 按键音」关掉（只影响电视版，手机版没有这一项）。

## 六、第一次使用

1. **装上并打开**。第一次进来首页会提示"**还没有设置数据源，请按上面的「设置」按钮添加**"——这是正常的，因为还没有片源。这张提示卡是**不能点的**，要用功能行里的「设置」。
2. **添加片源**：点「设置」→「**点播源**」→ 弹窗里填两项：
   - **名称**：随便起一个，比如"常用"（也可以不填）
   - **配置**：粘贴你拿到的片源接口地址

   填完按「确定」，等它把配置下载完。
   > 用遥控器打字很麻烦：电视上弹窗里有二维码，**用手机扫一下**就能在手机上填，电视这边输入框会自动填上，你再按「确定」。
   >
   > 首页功能行里的「推送」是同一套东西：电视上显示一个二维码和一个局域网地址，手机扫码打开那个网页，就能把文字/链接推到电视上（电视这一端只是显示，不需要按任何按钮）。
3. **回首页**：按「返回」，这时应该能看到「推荐」和各个分类了。
4. **调字号**（仅电视版）：进「设置 → 长辈设置 → 字号大小」，按一下换一档，觉得够大就停（屏幕小的电视别用"极大"）。
5. **锁定片源**（推荐）：进「设置 → 长辈设置 → 一键锁定」，选好数据源，按最下面的「一键锁定」。之后老人开机只要按「播放」就行。

## 八、播放时找不到能看的怎么办

软件会**自己想办法**，老人不用操作：

1. 先自动换这条片源的**其它线路**（按线路好坏挑）；
2. 还不行，就自动换到**其它数据源**的同名影片；
3. 手动点「换源」时，会提示"**正在查找其它站源……**"；
4. 实在找不到，才提示"**未找到同一影片的其他站源**"。

> 配合「站源管理」把老人压根打不开的源（比如网盘类）停掉，自动换源就只在能看的那些源里找，命中率更高。

## 十、常见问题

**Q：首页提示"还没有设置数据源"？**
A：还没添加片源。点上面的「设置」→「点播源」，填名称和配置地址。

**Q：整页只有一张提示卡，点它没反应？**
A：那张卡是说明用的，不能点。用功能行的「设置」进去添加片源（自启版是标题区右上角的齿轮）。

**Q：按返回键怎么退不出去？**
A：首页要 **4 秒内连按三次**才退出（第一下会提示「再按两次返回键退出」，后两下不提示）。在别的页面按返回只是回首页，本来就不会退出。另外，如果电视上已经把本软件设成「电视主页」，首页按返回键是**没有动作**的——这是故意的，和电视自带桌面一致。

**Q：播放时按返回，怎么先回到全屏画面了？**
A：返回是逐级退：先收起控制栏 → 再退出全屏 → 最后回首页。连按几下就到首页了。

**Q：提示"数据源已锁定，如需更换请先解锁"？**
A：锁定功能在起作用。进「设置 → 长辈设置 → 一键锁定 → 解锁」就可以了。

**Q：电视打开一直停在"正在连接网络…"？**
A：先看电视/盒子有没有联网。没网时它会停在这一屏等，网络恢复后自动继续。

**Q：首页显示"暂时连接不上，网络好了会自动重试"？**
A：数据源这次没取到内容（网络抖动或那个源暂时不通），不是软件坏了。网络好了会自动重试；手机上旁边还有「重新加载」按钮可以手动再来一次。

**Q：字太大，有的地方显示不全？**
A：把字号调小一档。屏幕小的电视建议不要用"极大"。

**Q：换壁纸 / 切主题色 / 改字号之后，首页要等一会儿才出来？**
A：6.0.4 之前的版本会整页重载（连数据源一起重新下载），现在不重载数据源了，只重画/重建界面。电视版重建后首页内容会重拉一次（约 1~2 秒）；手机版重建后首页和「推荐」会自动重新加载，不会停在旧数据。如果一直转圈不出来，多半是那个数据源本身就慢，按上面"暂时连接不上"那条处理。

**Q：恢复默认设置，收藏和历史会丢吗？**
A：不会。它只恢复这一页上的设置项，数据源、收藏、观看记录都保留。

**Q：为什么软件里什么内容都没有？**
A：这个软件本身不含任何影视内容，内容全部来自你自己添加的配置地址。

**Q：安装时提示"应用未安装"？**
A：换另一个位数的包（`armeabi_v7a`）试试；也可能设备里已经装过同一个软件的其他版本（比如先装了标准版又想换自启版），**先卸载再装**。

**Q：装的是自启版，但开机没有自动打开？**
A：①看「长辈设置 → 启动与桌面体检」第一项是不是"已关闭"；②部分电视（TCL / 雷鸟等）在「安全中心 / 权限管理」里默认禁止第三方应用自启，要点「允许」；③有些电视「关机」其实是待机，不会触发开机启动，得真正断电再上电。

**Q：自启版的应用页是空的 / 少了很多应用？**
A：应用页只列**有桌面图标**的应用（能点开的）。安卓 11 以后的电视对"能看到哪些应用"有限制，本软件只申请了"有启动入口的应用"这一项，没有申请"读取全部应用列表"；如果页面完全空白，通常是系统把包查询权限拦了，重启一次软件即可。

**Q：应用页里长按没有反应？**
A：遥控器上按住「确定 / OK」键别松，大约 1 秒进入管理。管理是"两步式"的：先选要做什么，再确认；隐藏起来的应用要按顶部「已隐藏」才找得回来。

**Q：体检页某一项一直显示"需要设置"？**
A：有些电视把对应的系统页裁掉了，跳不过去。体检页会提示"这台电视不支持直接跳转，请到系统设置里改"，按提示自己找那一项即可，不影响其它功能。

**Q：推送页只有一个二维码和一个地址，没有按钮，怎么用？**
A：这一页本来就是"给手机看"的：用手机扫二维码（或者在手机浏览器里输入那个地址），在手机网页里把文字或链接推过去，电视就会收到。电视这一端不需要按任何按钮，按「返回」退出即可。

**Q：手机版切了主题色 / 改了设置，首页内容会变吗？**
A：会重新加载一次（这正是为了让新设置后的内容立刻生效）。配置和源列表不会重新下载，所以很快。

**Q：两个版本能用同一个数据源配置吗？**
A：可以。配置和收藏/历史都存在本机，同签名覆盖安装不会丢。

### 13.2 构建

- 环境：JDK 21、Android SDK（compileSdk 37）、minSdk 24
- 编译前在根目录建 `local.properties`，填 `sdk.dir` 和签名四项（`storeFile` / `keyAlias` / `storePassword` / `keyPassword`）
- 出包：`./gradlew :app:assembleLeanbackRelease`（电视版）或 `:app:assembleMobileRelease`（手机版）
- 播放内核等预编译库已在 `app/libs/` 里一并入库，克隆后无需额外下载
- ⚠️ 改了 `app/src/main/` 下的东西（`Setting`、`ImgUtil`、`Clock` 等被手机版共用）**必须双端都重建**，否则手机包是旧的
- 产物默认落在 `../dist`（`dist/` = 标准版、`dist-autostart/` = 自启版）
- `MD5.txt` **没有 gradle 任务**：归档后在这两个目录里各跑一次 `md5sum *.apk > MD5.txt`

### 13.3 维护两个分支

本地有两棵开发树（`FongMi-TV/repo` = 标准版、`FongMi-TV/repo-autostart` = 自启版），发布时用脚本同步到本仓库的两个分支：

```bash
python sync-to-github.py --variant main          # 标准版 → main
python sync-to-github.py --variant autostart     # 自启版 → autostart
python sync-to-github.py --dry-run               # 只看会改什么
```

`README.md` / `CHANGELOG.md` / `NOTICE.md` / `.gitattributes` / `.gitignore` / `gradle.properties` 属于**人工维护**，任何一侧的源码都不会覆盖它们——所以两版的说明只需在这里写一次。
